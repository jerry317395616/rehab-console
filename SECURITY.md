# Security policy

Privately report suspected vulnerabilities using **Report a vulnerability** on the repository's [Security page](https://github.com/jerry317395616/rehab-console/security). Include the affected version, the relevant workflow and permissions, and a minimal reproduction using synthetic data. Keep credentials, session tokens, patient information, and private hostnames out of the report.

For a routine bug with no security impact, open a [GitHub issue](https://github.com/jerry317395616/rehab-console/issues).
